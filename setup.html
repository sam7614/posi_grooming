교수자 Google Sheets 연결

이 페이지는 설치 안내입니다. 학생 명단이나 접속키를 관리하는 화면이 아닙니다. 아직 웹앱 주소를 설정하지 않았다면 학생 답변은 수집되지 않습니다.

1. 시트에 앱 설치

  1. 교수자 자신의 비공개 학습기록 Sheets를 엽니다. 학생에게 편집 권한을 주지 않습니다.
  2. 확장 프로그램 → Apps Script를 누릅니다.
  3. 아래 Code.gs 전체 내용을 편집기 Code.gs에 붙여넣습니다.
  4. 파일 + → HTML에서 대문자 I의 Index를 만들고 아래 Index.html 전체 내용을 붙여넣습니다.
  5. 저장 후 원래 시트를 새로고침합니다. 학습기록 관리 → 1. 처음 설정을 실행하고 본인 프로젝트의 필요한 권한을 승인합니다.
  6. 학습기록 관리 → 2. 참여자 등록·키 재발급에서 시험 참여자 A01을 등록합니다. 개인키를 복사해 개별 보관합니다.

2. 웹앱 배포와 GitHub 연결

  1. Apps Script의 배포 → 새 배포 → 웹 앱을 선택합니다. 실행 사용자는 나(Me), 접근 대상은 학교 정책에 맞게 정합니다.
  2. 배포 후 /exec로 끝나는 웹 앱 URL을 복사합니다.
  3. GitHub 저장소의 config.js에서 빈 따옴표 안에 웹앱 URL을 넣고 저장합니다. 시트 URL이나 개인키는 넣지 않습니다.
  4. 학습페이지를 새로고침하고 학습기록 앱 열기를 누릅니다. A01과 개인키로 저장한 뒤 시트의 현재기록과 수정이력에서 수신을 확인합니다.

학교 정책으로 배포가 차단되면 담당자에게 허용 범위를 확인하세요. 주소만 설정했다고 수신 시험이 완료된 것은 아닙니다.
